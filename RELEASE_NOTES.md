# What's New in Chimanew v2.6.41

### 🎨 Instant Cover Updates & Custom Artwork Fixes
* **Instant Details Page Cover Refresh**: Fixed an issue where applying or changing a cover from the Artwork Picker or file manager would not update on the details page until the cover was tapped to open full-screen. The details page now immediately displays the custom cover.
* **Instant Library Grid & List Sync**: Updated Library Comfortable, Compact, and List grids to seamlessly prioritize custom covers over online provider posters as soon as a cover is applied.
* **Non-Library Entry Support**: Custom covers can now be applied and saved cleanly for any entry, even before adding it to your library.
* **Smart Memory Cache Clearance**: Coil's image memory cache is proactively purged upon cover changes, resets, or source exclusion changes, guaranteeing instantaneous visual feedback without stale cached images.
* **Reactive Artwork Exclusion Waterfall**: Toggling source exclusions in the Artwork Picker now instantly recalculates and updates the displayed cover and backdrop to the next preferred provider without leaving the screen.
