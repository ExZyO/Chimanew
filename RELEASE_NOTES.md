# What's New in Chimanew v2.6.54

### 🎨 Category Artwork Rules & Multi-Category Prioritization
* **Custom Artwork Source by Category**: You can now designate exact cover and banner providers for individual categories (e.g. AniList for Category 1, MangaDex for Category 2, and Default only for all other categories).
* **Separate Cover and Banner Controls**: Independently select cover sources (Waterfall, MangaDex, AniList, Bangumi, BookWalker, Naver, Kuaikan, Kitsu, Default Only) and banner sources (Waterfall, AniList, Bangumi, Naver, Kuaikan, Kitsu, None / Dark Canvas, Default Only).
* **Per-Category Fallback Behavior**: Configure whether a category strictly falls back to original default artwork or cascades through your global waterfall when its assigned provider doesn't have an asset.
* **Draggable Multi-Category Conflict Resolution**: When a manga belongs to multiple categories, drag and drop categories in the priority list to define exactly which category's artwork rule wins.
* **'All Other Categories / Uncategorized' Catch-All**: Easily configure a master default rule for manga outside your configured categories, keeping the rest of your library clean and default-only.
* **Instant Dynamic Updating**: Reordering or modifying category rules immediately refreshes covers and banners across your library, details view, and home shelves without requiring app restarts or cache wipes.
* **Fast Navigation**: Access Category Artwork Rules from both **Settings → Nuvio → Artwork** and via the new Palette shortcut in **More → Categories**.
